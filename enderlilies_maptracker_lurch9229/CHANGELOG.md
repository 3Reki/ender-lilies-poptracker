# Changelog

## 3.0.0 Randomized Start Update

- Added support for randomized start!
  - You can select your start in the settings, or connect to an archipelago session to set it automatically
- Logic update, now matches randomizer v2.4.4/archipelago v0.8
- Fixed locations that needed to be checked manually, and locations that were considered out of logic until it was checked
- No need to extract the folder inside the zip to use with poptracker anymore
- Luminant Aegis Curio's location and Go mode item will now correctly auto-track
- Compressed images to reduce the size of the pack
- A few glitched logic added
